РУКОВОДСТВО ИНЖЕНЕРА

Сначала проводник. Затем логика.

Тяните мышью по сетке, чтобы нарисовать непрерывный проводник. Соседние линии соединяются только проведённым между ними штрихом.

  • N и P — два типа кремния. Проведите кремний другого типа к середине прямого участка, чтобы создать транзистор.
  • N-транзистор пропускает сигнал при высоком уровне на управляющем проводнике. P-транзистор — при низком.
  • Металл лежит над кремнием. Слои соединяются только через контакт. Выводы платы подключаются металлом.
  • +VCC всегда под напряжением. Неподключённый проводник имеет низкий уровень. Транзистор реагирует на управление на следующем такте.
  • Shift меняет N/P при рисовании и включает стирание металла. Ctrl+Z/Y — отмена/повтор. Ctrl+C/X/V — работа с выделением. Delete — удалить. Esc — отменить вставку.

Для первого задания постройте четыре независимых инвертора: подайте VCC через P-транзистор на выход, а вход соедините с его управляющим N-проводником.
